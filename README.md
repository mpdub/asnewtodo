# asnew · To do

The admin list for asnew: what's done, what's on Monday and Tuesday, and what's in the diary.

- `index.html`: the page. No build step.
- `tasks.json`: the list itself. Change a task here and the page follows.

Ticks on the page are saved in each person's browser. To mark something done for both of you, set `"done": true` on it in `tasks.json`, or ask Claude to.

Every task links to its official source. It's a checklist, not legal or tax advice.
